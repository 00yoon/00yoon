# 수학 풀이 교실 (1차)

학생은 태블릿+펜으로 문제를 풀고, 선생님은 PC·태블릿에서 반 전체의 풀이를 **실시간**으로 봅니다.
필기를 **획(stroke) 단위 + 시간**으로 저장하므로 풀이 재생, 지운 흔적 보기, 멈춘 시간 확인이 가능하고, 2차 AI 분석에 그대로 쓸 수 있습니다.

## 기능 (1차)
| 구분 | 내용 |
|---|---|
| 계정 | 관리자 → 교사 계정 생성 · 교사는 여러 학급 담당, 한 학급을 여러 교사가 공동 담당 · 학생은 **학번 + 4자리 비밀번호** (엑셀 붙여넣기로 일괄 등록, 비밀번호 안내 카드 인쇄) |
| 문제 세트 | 교과서/학습지/즉석 · **공유** 시 다른 선생님이 수업에 쓰거나 복사해서 수정 |
| 문제 가져오기 | **PDF 영역 자르기** (원본 그대로) · **한글 hwpx** (글·그림·수식 자동 변환, 번호로 문제 분리, 검토 후 추가) · 사진/이미지 자르기 · 직접 입력(`$수식$`) |
| 수업 | 학급 + 문제 선택 → 시작하면 학생 화면에 자동 표시 · "모두 이 문제로 이동" · 수업 중 **즉석 문제**(사진/손글씨) · 전체/개별 메시지 |
| 학생 화면 | 펜 3색·굵기·획 지우개·되돌리기·전체 지우기 · **펜 전용 모드**(손바닥 방지, 손가락은 스크롤) · 답 제출(재제출 가능) · 힌트 없음 |
| 모니터링 | 학생 카드 실시간 필기 · 상태(풀이 중/막힘/미접속/제출/정답/오답) · 막힘 기준 시간 설정 · 막힘 먼저 정렬 |
| 크게 보기 | 실시간 · **풀이 재생**(속도, 멈춤 건너뛰기, 멈춤 위치 표시) · **지운 흔적**(빨간 점선) · **시간 색**(먼저 쓴 획=파랑→주황) · 소요 시간/획 수/지운 획/15초 이상 멈춤 |
| 기록 | 수업이 끝나도 학생별·문제별 풀이 다시 보기 |

정답을 넣어두면 제출 시 자동 비교합니다. 공백은 무시하고, 정답이 여러 개면 `|`로 구분합니다(예: `19/10|1.9`). 정답 여부는 **교사 화면에만** 표시됩니다.

## 실행
```bash
npm install
npm start          # http://localhost:3000
```
- Node.js 22.13 이상이 필요합니다. 내장 SQLite를 쓰므로 DB 설치는 필요 없습니다.
- 첫 실행 때 관리자 계정이 생성됩니다: `admin` / `admin1234`. **로그인 후 반드시 비밀번호를 바꾸세요** (우측 상단 → 내 계정).
  - 환경변수 `ADMIN_ID`, `ADMIN_PASSWORD`로 처음부터 지정할 수 있습니다.
- 데이터 위치는 `DATA_DIR`(기본 `./data`)입니다. 여기에 `app.db`와 `uploads/`가 들어가며, **이 폴더만 백업하면 됩니다.**

## 클라우드 배포
> Fly.io·Railway 단계별 안내, 환경변수, 백업, **학생 개인정보 외부 저장 안내**는 [DEPLOY.md](DEPLOY.md)를 보세요.

Docker 이미지 하나로 돌아갑니다. **`/data`는 반드시 영구 디스크(볼륨)에 연결하세요.** 연결하지 않으면 재배포할 때 데이터가 사라집니다.
```bash
docker build -t math-class .
docker run -p 3000:3000 -v math-data:/data -e ADMIN_PASSWORD=바꿀비번 math-class
```
- 볼륨을 지원하는 곳이면 어디든 됩니다(Fly.io, Railway, Render 유료 디스크, AWS Lightsail/네이버클라우드 같은 VPS 등).
- 학생 태블릿이 접속하려면 **HTTPS 주소**가 필요합니다. 위 서비스들은 기본 제공합니다.
- 실시간 연결에 WebSocket을 사용하므로 서버는 **1대(인스턴스 1개)** 로 운영하세요. 한 학교 규모에는 충분합니다.

## 구조
```
server/
  index.js     서버 시작 (정적 파일, API, 실시간)
  db.js        SQLite 스키마 · 비밀번호 해시
  api.js       REST API (로그인/학급/학생/문제 세트/수업)
  realtime.js  Socket.IO: 학생 필기 → 저장 → 교사 화면 전달
  hwpx.js      한글 hwpx 파서 (글·그림·수식, 번호로 문제 분리)
  hwpeq.js     한글 수식 스크립트 → LaTeX 변환
public/
  index.html   로그인 (학생/선생님)
  student.html, js/student.js     학생 풀이 화면
  teacher.html, js/teacher.js     교사 화면 (학급/문제 세트/수업)
  js/monitor.js                   실시간 모니터링 · 재생
  js/importers.js                 PDF/이미지 자르기 · hwpx 검토 · 직접 입력
  js/board.js                     필기 보드 (학생·교사 공용)
```
- 필기 데이터 형식: `{id, c:색, w:굵기, st:시작시각, p:[[x, y, 경과ms], ...], del:지운시각|null}`. 좌표는 1000×1400 논리 좌표입니다.
- `.hwp`(구버전) 파일은 한글에서 **hwpx 또는 PDF로 저장**한 뒤 올리세요.

## 2차 예정: AI 분석 (Google Gemini)
- 입력: 문제, 정답, 최종 풀이 이미지, 시간 색 + 지운 흔적 이미지, 과정 통계(멈춤/지움/소요 시간). 모두 1차 데이터에서 만들 수 있습니다.
- 교사에게 제공: 풀이 옮겨쓰기, 단계별 맞음/틀림, 오류 유형, 오개념, 과정 해석, 학생용 피드백 초안, 반 전체 요약.
- 학생에게 제공할 정보는 **미정**입니다. 실제 풀이로 정확도를 확인한 뒤 결정합니다.
